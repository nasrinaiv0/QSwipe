## Design and security
Exact active workspace/unit level_3/org_admin grant, live verified AAL2 session, independent default-off database and preview flags. Reuse onboarding command authorization and workspace transaction lock; no direct client writes. Server validates bounded inputs, caller-scoped UUID idempotency with canonical command hash and immutable receipts. No administrator self-transfer or transfer of role holders. Only same-workspace immediate transfers, both source/destination explicit grants; old roster inactive, new roster ID active, membership retained. No deletion/reassignment of historical IDs; returning to an old unit requires future versioned roster schema work. Onboarding lifecycle may need subsequent adaptation for multi-roster memberships; fail closed rather than silently updating wrong roster.

Recurring shifts: bounded weekly series 2–8 occurrences, explicit local date/time and UTC offsets; validate every occurrence by existing timezone round-trip; entire series atomic, reject DST offset changes instead of guessing. Explicit date boundaries handle overnight. Versioned edits and cancellations only before opening and before attendance/pass activity. Replace via new session/immutable eligibility snapshot and append old-session retirement event, preserving originals; version chain keyed by root and predecessor; optimistic expected version. P3/P5 exclude retired sessions and deny direct attendance. PR14 legacy schedule overlap query must exclude retired managed sessions to permit replacement. No editing history after start.
Leave: scoped admin records/cancels full-shift excused leave for a snapshotted roster before opening, reason category only, not diagnosis; cannot mark excused employee via P3. Holidays: explicit admin classification per local date (regular/special/other), versioned append-only records, no automatic legal calendar/payroll or wage computation. Holiday classification uses shift start local date, not hourly statutory segmentation. No implicit absence.
Reporting: scoped managed shifts only, bounded date range 31 days and <=100 shifts, exclude retired from active totals; retain history in version list. Count planned eligibility, present, absent, excused, unmarked; classify future separately from completed (no inferred absence). Reconcile partition and attendance events/correction projection; flagged mismatch blocks release. Historical scope is current administrator grant to old unit, not access by former employee. No employee PII in aggregates.
