# Live team rooms — staging only
Parent PR #17 ff27e55fc0600fdba2390169cccb2cd3287e8293. No remote database, paid resources, merges or production changes. Separate standalone Node server serving built static app plus same-origin JSON room API, no dependencies beyond current app. Only starts with explicit QSWIPE_ROOM_STAGING=1 and rejects VERCEL_ENV=production/NODE_ENV=production; default bind loopback. Vercel static preview is not a shared server: show unavailable message unless an isolated room server is running. No claims of deployed live service.
Room lifecycle: host creates a temporary room, shares QR invitation URL fragment with random 128-bit invitation code. Separate 256-bit per-participant bearer credentials held in browser memory only; invite grants joining as guest, never host. Up to 12 players, 100 rooms, 2-hour TTL, 30 rounds per room, no new joins during round; name max 24 characters, no attendance/workspace identities. Host can close. Room state serialized by single process; no persistence across restart, no multi-instance deployment. Request body cap, bounded rate limit by source IP, no CORS, no-store, exact same-origin browser POST checks, no credentials in URLs/logs, no personal information or monetary prizes. No cross-device login integration. 
Games: host starts wheel, duck race or simultaneous five-question trivia. Server chooses crypto-random draw winner and fixed wheel target/race ranking, publishes common start/end epoch; clients animate from server clock and settle on authoritative outcome. Trivia answer key stays private until reveal, one answer per player/question, deadline server-authoritative, host advances only after reveal. Points awarded once per completed round, draw winner 20, trivia 10 per correct answer, 10 participation for answering all five; separate room leaderboard and team totals, cosmetic badges. Team competition uses average points per participant (show totals separately), no attendance or pay consequences. Late polling renders current state; no client-controlled awards. Poll every 1s while visible, stop on page exit; reduced motion respects browser preference. In-memory bearer lost on refresh; rejoin with new identity only in lobby, not automatic score restoration. 
UI: standalone /rooms/ with link from Play and Today, guest join without creating workspace, QR using existing QR renderer via separate Vite entry, responsive room lobby/scoreboard, animated ducks and wheel, accessible controls, clear connectivity status. 
Tests: Node unit protocol/HTTP tests including isolation, host permissions, duplicate answers, server scoring, expiry and room caps; Chromium independent contexts on actual local server, QR join route, sync wheel/race, five trivia questions, team scores, mobile/dark/reduced motion and screenshots. Existing PR17 regressions retained. No paid or remote setup. Independent Claude/frontend review instructions only, not claim performed. Production launch requires approved shared hosting, restart/reconnection handling, device tests and basic abuse review.
